# UI Styling Instructions

Follow this visual system for all interface work in this project:

- Use the project’s calm, earthy palette with green as the primary accent and warm neutral tones for supporting surfaces.
- Favor soft, light backgrounds with darker text for readability and a polished, modern feel.
- Keep the overall look consistent with the existing brand: muted greens, cream paper backgrounds, dark ink text, and subtle borders.
- Avoid harsh, saturated, or high-contrast color schemes unless the task explicitly calls for it.

## Button Rules

- All buttons should use a light background color.
- Button text must be dark and bold.
- Use a subtle border or low-contrast outline to keep the controls clean and readable.
- Maintain strong contrast between button background and text so the controls remain accessible.
- Prefer soft neutral or pale green backgrounds over dark button fills unless a specific interaction state requires otherwise.

## Typography and Layout

- Use bold, clean sans-serif headings and readable body text.
- Keep spacing consistent between sections, cards, and controls.
- Use rounded but restrained corners and subtle shadows only when they support clarity.
- Prefer simple, clean UI patterns over decorative or noisy styling.

## Examples of acceptable UI choices

- Light green or cream button backgrounds with dark charcoal or deep green text
- Soft neutral panels with dark ink labels
- Subtle green accents for active states, not dark-heavy fills

## Examples to avoid

- Dark buttons with light text unless the design specifically requires a contrast-driven accent
- Bright, distracting colors that clash with the brand palette
- Buttons with light text on a pale background that reduce readability
